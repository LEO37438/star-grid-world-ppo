**Star Grid World – Reinforcement Learning using Python**

Developed **Star Grid World**, a custom 7×7 reinforcement learning environment using Python and the Gymnasium framework, where an intelligent agent learns to navigate a grid by collecting stars, avoiding obstacles, and maximizing cumulative rewards. The project involved designing the complete environment from scratch, including grid layout, state representation, action space, reward mechanism, and episode termination conditions to simulate a sequential decision-making problem.

Implemented the **Proximal Policy Optimization (PPO)** algorithm using Stable-Baselines3 and PyTorch to train an Actor-Critic model capable of learning optimal navigation strategies through continuous interaction with the environment. The agent was trained for **300,000 timesteps**, during which various hyperparameters and reward-shaping techniques were tuned to improve learning efficiency, policy stability, and convergence. Training performance was evaluated using metrics such as cumulative rewards, episode lengths, policy loss, value loss, and explained variance to monitor and optimize the model.

Developed the project using a modular software architecture by separating the environment, training pipeline, visualization, and evaluation components, resulting in clean, maintainable, and reusable code. Integrated Pygame to provide real-time visualization of the agent's movement and learning behavior, making it easier to analyze performance and debug the environment.

This project strengthened my proficiency in Python programming, object-oriented programming, data structures, debugging, and algorithm implementation while providing hands-on experience with machine learning and reinforcement learning frameworks. It enhanced my analytical thinking and problem-solving skills through environment design, reward engineering, model optimization, and performance evaluation. The project demonstrates my ability to develop end-to-end software solutions, write scalable and maintainable code, and apply modern AI techniques to solve complex computational problems.

**Technologies Used:** Python, Gymnasium, Stable-Baselines3, PyTorch, NumPy, Pygame, Matplotlib, Git.
